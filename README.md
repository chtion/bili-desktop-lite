# Bili Lite 0.10.0

Windows 10/11 x64 非官方 B站桌面 App，提供独立界面与昼夜主题。

## 0.10.0 开发版

- 应用更新已接入项目的私有 [GitHub Releases](https://github.com/chtion/bili-desktop-lite/releases)。检查时使用本机 Git Credential Manager 中已有的 GitHub 登录。账号需有仓库读取权限。
- 更新界面显示版本说明、下载进度和校验状态。下载可取消并重新开始。安装器仅在文件大小与 SHA-256 均通过校验后启动。
- 首次从 0.9.0 进入私有仓库更新线时，先退出旧版，再运行本次 Releases 中的对应 EXE。之后可以在「设置 → 应用更新 → 检查 GitHub 更新」获取新版。
- 源码与版本标签保存在 Git，两个 EXE 附在对应的 GitHub Release。后续发布见 [发行流程](RELEASING.md)。

## 0.9.0 开发版

- 网页全屏时，返回键和侧栏开关都在左上角。收起左栏后，仍能用返回键回到上一页。
- 历次发布按 0.x 开发编号重新列在[版本索引](dist/archive/版本索引.md)中。旧包保留原文件名、内嵌版本和 SHA-256 校验值。
- 从旧编号切换到 0.9.0 时，先退出正在运行的旧版，再直接运行新版 EXE。旧版本的更新器会把 0.9.0 判为更低版本。后续按 0.10.0、0.11.0 继续编号，应用内更新使用 0.x 发布包。

## 0.8.0（原 2.6.0）

- 「番剧探索 → 索引」使用 B站当前筛选条件，可组合选择地区、年份、风格、连载状态、配音和付费类型等。番剧与国创分别提供适用条件。
- 搜索有「综合、视频、用户、番剧」四个标签。综合页汇总相关分类，分类页可继续翻页。用户与番剧结果直接进入应用内个人空间或选集页。
- 最小窗口为 720 × 500。普通播放在窄窗将详情移至下方，网页全屏的右栏会浮在画面上，可随时收起。
- 播放页右上角按实际标题栏空间定位置顶按钮，播放器上方也有置顶开关。切换后显示状态，退出视频页时结束置顶。

## 0.7.0（原 2.5.0）

- 侧栏「番剧探索」提供 B站番剧和国创目录，支持按连载状态、热度、更新时间和评分筛选，不需要先追番。
- 播放器工具栏直接显示「倍速」和「字幕」。网页全屏时，左栏在左上角按需展开，悬浮在视频画面上。
- 简介增加 UP 主数据、视频标签、在线人数和可点击章节。评论区增加最热/最新、置顶评论与楼中楼。
- 播放历史会记录每个分 P 和每集剧集的时间点，重新打开时自动续播。登录后，默认同步实际播放进度到 B站。可在设置中关闭官网同步，本机记录继续保存。
- 设置中的「应用更新」支持选择含 `bili-release.json` 及新版 EXE 的发布文件夹。免安装版在原 EXE 所在目录启动新版文件。

## 0.6.0（原 2.4.0）

- 首页使用 B站网页端推荐，按当前会话区分「账号推荐」「游客推荐」和「热门备用」。加入账号、退出或切换账号后会重新获取内容。
- 在播放器的「设置 → 字幕」中选择 B站提供的普通字幕和 AI 字幕。可用轨道取决于视频和账号权限。
- 视频页支持点赞、确认投币、选择 B站收藏夹、关注 UP 主和复制分享链接。「合集 / 分 P」中可切换当前投稿的分 P 与合集中的其他投稿。
- 「我的追番」支持追番、追剧和观看状态筛选，可查看正片与额外章节并用内置播放器播放可用剧集。
- Logo 位于侧栏最上方。返回、收起按钮统一样式，收窄后也可以点击 Logo 刷新。旧版发行文件存放在 dist/archive 下的各版本目录。

## 0.5.0（原 2.3.0）

- 网页全屏采用折叠屏式布局：左侧播放、右侧简介/评论/推荐/分集。点击两栏交界处的箭头可收起或展开详情，视频保持播放。
- 播放器工具栏的网页全屏按钮可切换布局，Esc 退出。F11 仍为窗口全屏。
- 左下角齿轮打开设置：默认网页全屏、默认展开详情、老板键暂停选项、外观和快捷键。
- 老板键默认 Ctrl+Alt+B，隐藏窗口并静音，再按恢复；默认同时暂停视频。隐藏后托盘图标也能恢复窗口，恢复后手动继续播放。
- 播放时右上角、最小化按钮旁的图钉可切换窗口置顶，默认快捷键 Ctrl+Alt+P；离开视频页自动取消置顶。
- 快捷键可点击输入框录制，清空可禁用。重复或被其他应用占用时显示错误，保存失败不覆盖之前的设置。
- 返回键位于侧栏最上方；首页图标和应用标志会刷新下一批推荐。
- 默认布局设置在下一次进入视频时生效。设置保存到本机用户资料目录，升级保留。

## 使用

- dist/Bili-Desktop-Lite-0.10.0-Portable-x64.exe：免安装，双击运行。首次需等待运行环境解压。
- dist/Bili-Desktop-Lite-0.10.0-Setup-x64.exe：安装版，可创建快捷方式。
- 左上角按钮可展开或收窄为图标栏，带过渡动画；进入视频默认收窄。左下角头像打开账号面板。
- 首页「刷新」会请求一批新推荐；榜单、搜索和账号列表会重新获取内容，并反馈刷新结果。向下浏览后右下角可回到顶部。
- 搜索支持关键词、BV 号和 B站视频链接。爱心保存到本地收藏；播放历史也仅保存在本机。
- 在账号面板选择登录后自行完成 B站官方登录。头像、资料、关注、粉丝、收藏夹、动态与个人空间在应用内展示；关注列表中的 UP 主可点开资料与投稿。
- 视频详情的「收藏」与 B站收藏夹同步。「本地收藏」保存在当前电脑。
- 视频页采用左右双栏：左侧播放和简介，右侧切换推荐、评论、分集。两边可独立滚动。
- 内置 Artplayer + Shaka DASH 播放器，直接播放 B站音视频流。支持暂停、拖动、音量、倍速、可用画质切换、弹幕显示开关、全屏、网页全屏、画中画。
- 弹幕和评论为只读展示，弹幕默认限制密度。可用画质、字幕和剧集取决于 B站返回的账号权限。已验证公开番剧的播放流。
- Ctrl+K / Ctrl+L 搜索；Alt+左箭头返回；F5 刷新；F11 窗口全屏；Esc 退出全屏或返回。播放器激活时也可使用空格与方向键。

## 构建与检查

npm ci → npm run vendor → npm run check → npm run smoke → npm run test:account → npm run test:desktop → npm run test:features → npm run test:services → npm run pack:win

播放器依赖固定版本，构建时复制到 src/vendor，只加载本地脚本。许可证同目录保留。安装包不包含测试与测试数据。

真实网络验证：首页换批、搜索、封面、视频音频解码、暂停/拖动/倍速/画质切换、公开 UP 主资料和投稿。账号收藏夹、关注/粉丝分页、动态、失败提示、登录状态变化使用隔离的测试响应验证，未代用户登录。测试资料目录与正式用户资料独立。2.3 还验证了全屏布局切换、折叠时不中断播放、老板键隐藏/静音/暂停/恢复、真实窗口置顶、快捷键注册/录制/冲突回滚、设置持久化和侧栏返回。

应用继续使用原来的 %APPDATA%/Bili Desktop Lite，原有登录和本地收藏可沿用。公开接口可能随 B站调整；网络或权限不满足时会显示错误，可在应用内重试。EXE 尚未做数字签名。

## 开源组件

- [Artplayer](https://github.com/zhw2590582/ArtPlayer)：5.4.0，MIT；弹幕插件 5.3.0，MIT。
- [Shaka Player](https://github.com/shaka-project/shaka-player)：5.3.5，Apache-2.0，负责 DASH 音视频同步、缓冲和切换。
- Electron 45.3.3。远程内容与 Node.js 隔离；视频 CDN 请求经主进程限定域名并保留字节范围，登录 Cookie 不发送到界面脚本。
